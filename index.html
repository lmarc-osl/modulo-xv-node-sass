01

O que é o Node.js?

O Node.js é um ambiente que permite executar código JavaScript fora do navegador.

Tradicionalmente, o JavaScript era associado principalmente aos navegadores.

Uma nova perspectiva JavaScript além do navegador.

O Node.js amplia o lugar onde podemos utilizar JavaScript.

Por exemplo, quando escrevemos:

JavaScript 
console.log("Olá, mundo!");

o navegador pode interpretar e executar esse código. Com o Node.js, podemos executar JavaScript diretamente no computador, utilizando o terminal.

Uma característica importante do Node.js é que ele possui um gerenciador de pacotes, o npm (Node Package Manager).

02

Node.js e o npm

Ao instalar o Node.js, normalmente também temos acesso ao npm.

O ambiente Node.js executa JavaScript fora do navegador.
O ecossistema npm ajuda a administrar pacotes JavaScript.

Verificando o Node.js

Podemos verificar se o Node está instalado através do terminal:

Terminal 
node --version

Ou:

Terminal 
node -v

O terminal deverá retornar a versão instalada, por exemplo:

Output 
v22.x.x

Verificando o npm

Também podemos verificar a versão do npm:

Terminal 
npm --version

Ou:

Terminal 
npm -v

O terminal deverá retornar algo semelhante a:

Output 
10.x.x
03

Node.js ≠ npm

É importante não confundir os dois:

Ambiente de execução

Node.js

Ambiente que permite executar JavaScript fora do navegador.

Gerenciador de pacotes

npm

Gerenciador utilizado para instalar e administrar pacotes JavaScript.
