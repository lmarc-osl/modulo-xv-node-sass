07

O papel do package.json

Quando trabalhamos com projetos Node/npm, um arquivo muito importante é o:

arquivo do projeto 
package.json

Ele funciona como uma espécie de descrição do projeto e pode registrar informações como:

Nome do projeto

Identificação do projeto.

Versão

Versão atual do projeto.

Scripts

Comandos utilizados no projeto.

Dependências

Pacotes necessários para o projeto.

Dependências de desenvolvimento

Ferramentas necessárias durante o desenvolvimento.

VIS
O projeto também é uma experiência visual Imagem decorativa para quebrar o bloco de código e criar ritmo na leitura.

Exemplo

package.json 
{
  "name": "meu-projeto",
  "devDependencies": {
    "sass": "^1.0.0"
  }
}
Por que isso é importante?

A ideia é que o projeto saiba quais pacotes precisa para funcionar ou ser desenvolvido.

Isso é especialmente importante quando trabalhamos em equipe ou quando precisamos reinstalar um projeto depois de formatar o computador.

09

O que você deve saber ao terminar esta aula

Ao final desta primeira aula, você deve conseguir explicar:

Node.js

É um ambiente que permite executar JavaScript fora do navegador.

npm

É o gerenciador de pacotes utilizado no ecossistema Node.js.

Pacote

É um conjunto de código que pode ser instalado e utilizado em um projeto.

Sass

É uma ferramenta que amplia as possibilidades do CSS e que pode ser instalada através do npm.
